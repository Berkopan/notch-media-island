Notch Media Island

TR: ZIP’i açın, Notch Media Island.app dosyasını Uygulamalar’a sürükleyin ve açın.
EN: Unzip, drag Notch Media Island.app to Applications, then open.

macOS 14+ required. arm64 = Apple Silicon (M-series), x86_64 = Intel.
No Xcode or developer tools needed for this prebuilt app.

This app is ad-hoc signed, NOT Developer ID signed or notarized by Apple.
macOS may block it. Verify the source and consult Apple’s official guidance:
https://support.apple.com/en-us/102445
The project does not disable system security or remove quarantine attributes.

Hover over the notch. No Dock icon is expected.
Menu bar waveform: Çıkış = Quit, Medya bağlantısını yenile = Reconnect.
Only the active system Now Playing session is shown. Some players do not
publish media information or support seeking. Private APIs can change.

are in this ZIP and inside the app’s Resources folder.
